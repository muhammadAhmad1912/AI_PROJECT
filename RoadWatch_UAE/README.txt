ROADWATCH UAE — LOCAL DEMO

Open index.html in a modern browser. GPS and clipboard work best on localhost or HTTPS.

To run on Windows: open this folder in VS Code, choose Open with Live Server, or run `python -m http.server 8000` and visit http://localhost:8000.

Features: photo upload and preview, browser GPS capture, Google Maps link, report summary preview, copy/download summary, print/save as PDF, and TAMM link.

The Teachable Machine AI area is currently a placeholder. Connect an exported TensorFlow.js model before claiming real predictions.

This is a student prototype and does not submit directly to TAMM or another UAE government system.
